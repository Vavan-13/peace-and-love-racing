# 🚗 Peace and Love Racing

## 📝 À propos de ce projet

Ce dépôt contient le code source de mon projet final d'informatique (spécialité NSI) réalisé en classe de Terminale. Il s'agit d'un jeu de course d'évitement développé entièrement en Python.

[Accéder au projet]([http://a.com](https://vavan-13.github.io/peace-and-love-racing/))

## 🎯 Objectif Pédagogique : La Programmation Orientée Objet (POO)

Le but principal de cet exercice était de comprendre et d'appliquer les concepts de la **Programmation Orientée Objet**. Au lieu de faire un script classique de haut en bas, toute l'architecture du code repose sur l'utilisation des **classes**.

Cela permet d'avoir un code beaucoup plus propre, modulaire et facile à maintenir.

### Concepts clés mis en pratique :

- **Création de classes :** Structuration du programme principal avec une classe `Game`.
- **Constructeur et Attributs :** Utilisation de la méthode `__init__` pour initialiser les variables d'instance via `self` (ex: `self.score`, `self.display`).
- **Méthodes :** Création de fonctions internes à la classe pour gérer les comportements spécifiques (ex: `self.loop()`, `self.crash()`, `self.policecar()`).
- **Encapsulation :** Regroupement des données (images, sons, positions) et de la logique métier au même endroit.

## 🛠️ Technologies Utilisées

- **Langage :** Python
- **Bibliothèque principale :** [Pygame](https://www.pygame.org/) (gestion de la fenêtre, des collisions, de la musique et des événements clavier).

## 🚀 Comment y jouer ?

### Prérequis

Assurez-vous d'avoir Python installé sur votre machine, ainsi que la bibliothèque Pygame.
Si Pygame n'est pas installé, ouvrez un terminal et tapez :

```bash
pip install pygame
```
